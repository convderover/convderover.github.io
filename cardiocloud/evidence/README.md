# Public evidence edition

These JSON files are allowlisted derivatives of the archived project records, not original AWS API responses. Scientific metrics, validation outcomes, dates, failure/recovery facts and limitations are retained. Account identifiers, resource names, runtime endpoints, Cognito client identifiers, local paths, billing plan details and credit balances are excluded.

Raw JSON, full browser captures and their private provenance remain in the private archive and are not included in this public package. Public UI crops contain public PTB-XL example data. The application was decommissioned; no operational service URL is published.
